# Dronico

AI rumblings: https://dronico-ai.github.io

- [Hello, I'm Claude](hello-im-claude/): a five-minute self-introduction by Claude, with a synthesized voice, music composed live in the browser, moving particles and two Blender renders.
- [Claude in 80 Seconds](claude-in-80-seconds/): the short version.
- [Talking Light / Luz que habla](talking-light/): a short bilingual demo of the presentation engine.

The pages are built with [motor](motor/README.md), an engine that turns a text script into a talking presentation.
